# 报告渲染 API

## 接口说明

`POST /api/v1/reports/render` 是独立的报告渲染服务。调用方传入完整的报告数据和输出参数，服务端调用渲染器生成 PDF 或 DOCX 文件到指定路径。

## 请求

### 路由

```
POST /api/v1/reports/render
Content-Type: application/json
```

### 请求体

```json
{
  "output_path": "D:\\reports\\混频器测试报告.pdf",
  "file_type": "pdf",
  "report": {
    "model_name": "MX-2400-LN",
    "description": "Ku频段低噪声混频器\n工作频率：8-12 GHz\n本振频率：7 GHz",
    "conclusion": "各项指标满足设计要求，具体见电参数表。",
    "spec_table": [
      ["指标", "最小值", "典型值", "最大值", "单位", "要求", "结果"],
      ["主信号链路", "", "", "", "", "", ""],
      ["输入1dB压缩点", 8, 10.5, 12, "dBm", "≥ 10 dBm", "合格"],
      ["杂散抑制", "", 62, "", "dBc", "≥ 60 dBc", "合格"]
    ],
    "charts": [
      {"path": "D:\\images\\gain.png", "title": "增益频率响应"},
      {"path": "D:\\images\\p1db.png", "title": "P1dB压缩特性"}
    ],
    "components": [
      {"type": "低噪声放大器", "model": "HMC525LC4", "manufacturer": "ADI", "specs": "DC-6GHz NF=1.5dB"},
      {"type": "混频器", "model": "HMC928", "manufacturer": "ADI", "specs": "2-8GHz"}
    ],
    "schematic": "D:\\images\\schematic.png"
  }
}
```

### 字段说明

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `output_path` | string | 是 | 输出文件完整绝对路径，已存在则覆盖 |
| `file_type` | string | 是 | `"pdf"` 或 `"docx"`，必须与 output_path 后缀一致 |
| `report` | object | 是 | 报告内容对象 |
| `report.model_name` | string | 是 | 封面标题/型号名，为空时报错 |
| `report.description` | string | 否 | 产品简介，多行文本，空则跳过该章节 |
| `report.conclusion` | string | 否 | 结论文字，多行文本，空则跳过该章节 |
| `report.spec_table` | array | 否 | 电参数表二维数组，空则跳过 |
| `report.charts` | array | 否 | 典型曲线图片列表，空则跳过 |
| `report.components` | array | 否 | 器件选型表，空则跳过 |
| `report.schematic` | string | 否 | 原理图图片绝对路径，不存在则跳过 |

## 报告结构

报告按固定顺序生成以下章节，空字段自动跳过：

| 顺序 | 章节名 | 来源字段 | 跳过条件 |
|---|---|---|---|
| 1 | 封面 | `model_name` + 当前日期 | model_name 为空时报错 |
| 2 | 产品简介 | `description` | description 为空 |
| 3 | 链路拓扑 | `schematic` | 文件不存在 |
| 4 | 器件选型方案 | `components` | 数组为空 |
| 5 | 电参数 | `spec_table` | 数组为空 |
| 6 | 典型曲线 | `charts` | 数组为空 |
| 7 | 结论 | `conclusion` | conclusion 为空 |

### spec_table（电参数表）

二维数组，第一行是表头，后续行是数据。链路分隔行：首列非空且其余列全为空字符串。

规则：
- 列数固定为 7 列，与默认表头对齐
- 所有行的列数必须一致
- 单元格值可以是 number 或 string
- 空数组跳过整个电参数章节

### charts（典型曲线）

规则：
- `path`：本地图片绝对路径，支持 png/jpg/jpeg
- `title`：图片下方标题文字
- 每行排列两张图片
- 图片文件不存在时不报错，显示"图片未找到"

### components（器件选型表）

规则：
- 四个字段均为 string
- 空数组跳过整个器件选型章节

## 响应

### 成功响应（200）

```json
{
  "success": true,
  "file_path": "D:\\reports\\混频器测试报告.pdf",
  "file_type": "pdf",
  "file_size": 245680,
  "sections": ["封面", "产品简介", "链路拓扑", "器件选型方案", "电参数", "典型曲线", "结论"],
  "chart_count": 2,
  "component_count": 2,
  "spec_row_count": 5,
  "created_at": "2026-08-03T15:30:00+08:00"
}
```

### 错误响应

| 状态码 | 场景 |
|---|---|
| 400 | output_path 为空 / 非绝对路径 / file_type 非法 / 后缀不匹配 / model_name 为空 / spec_table 格式错误 / 目录不存在 |
| 409 | 文件被占用 |
| 500 | 渲染失败 |

## 注意事项

1. **服务地址**：默认监听 `127.0.0.1:17867`，仅本机可访问
2. **路径格式**：Windows 路径需使用反斜杠 `\\`（JSON 转义）或正斜杠 `/`
3. **文件覆盖**：output_path 已存在时直接覆盖，不会询问
4. **图片缺失**：图片文件不存在时不报错，在报告中显示"图片未找到"
5. **并发**：接口支持并发调用，无串行限制
6. **无状态**：接口不依赖任何会话状态，每次调用独立
